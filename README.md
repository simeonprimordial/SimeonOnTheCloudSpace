## Stack

- **UI:** React 19, Vite 8, Tailwind CSS v4
- **Quality:** Oxlint, GitHub Actions (build, quality, deploy)
- **Hosting:** GitHub Pages (automated on `main`)

---

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to GitHub Pages.

One-time Pages setup: **Settings → Pages → Source → GitHub Actions**.
